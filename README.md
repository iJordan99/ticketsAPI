
# 🎫 Laravel Tickets API

A work-in-progress ticket management system built with Laravel 11 featuring a robust RESTful API for handling support tickets, user management, and engineer assignments.

## 🚀 Features

- **User Management**: Authentication and user roles (users, engineers, admins)
- **Ticket System**: Create, read, update, and delete tickets with priorities and statuses
- **Engineer Assignment**: Assign engineers to tickets and track their progress
- **Comments**: Add comments to tickets for better communication
- **Audit Logging**: Track changes and actions within the system
- **API Versioning**: Structured API with v1 endpoints
- **Permissions**: Role-based access control with policies
- **Documentation**: API documentation with Scribe

## 📋 Requirements

- PHP ^8.2
- MySQL Database
- Composer
- Node.js & npm
